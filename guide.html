What is the post-market-intelligence Skill?

A skill is a saved set of instructions that tells Claude exactly how to build the post-market report — what data to fetch, how to structure the analysis, and how to format the output. Think of it as a playbook Claude reads before starting every report.

  • Trigger it by typing "post-market report", "EOD report", "weekly review", or "expiry analysis"
  • It fetches data from 14 web searches (indices, sectors, FII/DII, macro, commodities) and Zerodha Kite MCP (live F&O OI for expiry reports)
  • Outputs a single interactive HTML file — light theme, sticky nav bar, sortable colour-coded tables, collapsible sections
  • Report types: Daily (every trading day) · Weekly Review (every Friday, 5-week comparison) · F&O Expiry Special (last week of each monthly series)
  • If you provide FII/DII data as a screenshot or text, it overrides the web search for those fields
📁
Skill file location: /mnt/skills/user/post-market-intelligence/SKILL.md — this is the master instruction file. If it ever needs updating, changes are made here and the skill is repackaged.

The 7 Sections of Every Report

Every daily report contains 6 sections (§0–§5). Section §6 is added automatically in the last week of a monthly F&O series, or always in a weekly review.

§0
Executive Scorecard
Quick-view dashboard. Index closes, VIX, FII/DII net flows, PCR. Commodity row: Brent Crude, Gold, Silver, Aluminium, Copper MCX prices. 3–4 key theme bullets.
§1
Nifty Movement & Narrative
Full OHLC table, 1D/1W/MTD performance. 4–6 narrative bullet points explaining exactly what moved the market and why. Global cues table (Dow, NASDAQ, Crude, USD/INR, US 10Y).
§2
Macro & Policy Dashboard
Any RBI, SEBI, or data releases in the last 48 hours. CPI, WPI, IIP, PMI, GST, RBI rate decisions — each as a structured card with bullet-point market impact.
§3
Breadth & Sector Rotation
5-day Advance/Decline comparison across all major indices. % of stocks above 200/50/20 SMA. Sector rotation insight (what to buy, what to avoid). Currency & commodity 5-day snapshot.
§4
FII / DII Flow Dashboard
Daily buy/sell/net table. 5-day trend comparison. FII F&O futures position. Interpretation: what the flows mean for tomorrow and the coming week.
§5
F&O Intelligence
PCR, Max Pain, India VIX. Strike-wise Call/Put OI table. Key support and resistance levels from options OI. Next-session outlook with directional bias.
§6
F&O Expiry Intelligence
Live from Zerodha Kite MCP. Daily OI pattern table for Nifty & BankNifty futures (LB / SB / SC / LU classification). Top-7 Nifty50 stocks OI analysis. Three expiry scenarios with probability. Triggers for swift moves. Trading framework for final sessions.
⚡
§6 trigger rule: Added automatically in Weekly Reviews (always) and in Daily reports when the monthly expiry is 5 or fewer trading days away. It uses live Kite MCP data — Kite login is required before running.

GitHub Pages — How Reports are Hosted

Why GitHub Pages?

Blogger strips the styling from HTML reports when pasted directly — tables lose colours, the nav bar disappears, and the report becomes unreadable. The fix is to host the HTML file on GitHub Pages and embed it in Blogger via a single iframe link. This way, readers see the fully styled report exactly as designed.

Why We Use an iframe — Not Direct HTML

When you paste the full HTML report into Blogger, it strips all the CSS styling — the colour-coded tables, sticky nav bar, cards, and collapsible sections all disappear. The report becomes unreadable plain text.

The solution: paste a single iframe tag into Blogger that loads the report from GitHub Pages. Readers see the fully styled, interactive report. Blogger just acts as the frame.

How to Create a New Blogger Post — Step by Step

1
Go to Blogger and create a new post
blogger.com → Your Blog → New Post. Give it a proper title like: Post-Market Intelligence — 26 August 2026
2
Switch to HTML mode
In the editor toolbar, click HTML (not Compose). This is critical — pasting in Compose mode will strip the iframe tag.
3
Delete everything in the editor and paste the iframe code
Copy the code below, change the filename in the URL to match today's report, and paste it into the HTML editor.
4
Add labels and publish
Add labels: Nifty, BankNifty, FII/DII, F&O, Post-Market, Markets with Rajan. Then click Publish.

The Daily Workflow — End to End

This is the complete daily process, from market close to Blogger post published. The entire workflow typically takes 5–8 minutes after market close.

1
Provide FII/DII data (optional but recommended)
Take a screenshot of the NSE/5paisa cash market summary table and paste it into Claude. This gives accurate FII/DII numbers that web search sometimes misses.
2
Trigger the report
Type: "post-market report for [date]". If it is expiry week or a weekly review day, Claude adds §6 automatically. If Kite data is needed, Claude will prompt for login.
3
Authorise Kite (if prompted)
Click the Kite login link Claude provides. Authorise in the browser. Tell Claude "login done". Claude then pulls live F&O OI data from your Zerodha account.
4
Claude generates the HTML report
Takes 3–5 minutes. Claude runs 14 parallel web searches + Kite API calls. The report appears as a downloadable HTML file in the chat.
5
Push to GitHub Pages
Paste your GitHub classic token (ghp_…) and say "push today's report". Claude uploads the HTML to reports/2026/MM/, updates the index page, and gives you the Blogger iframe code.
6
Create Blogger post
Go to Blogger → New Post → HTML mode → paste the iframe code Claude provides → add labels → Publish. Done.

Automation Built In

  • §6 auto-trigger: Claude checks if expiry is ≤5 days away and adds the Kite MCP OI analysis without being asked
  • Weekly review auto-trigger: On Fridays, Claude switches to 5-week comparison framework automatically
  • Index update: Every GitHub push automatically updates the landing page archive with the new report
  • Scenario tracking: On expiry day, Claude reviews the prior day's 3 scenarios and tells you which one played out
  • FII/DII override: If you paste FII/DII data, Claude uses your numbers instead of web search — more accurate
💡
Tip: Keep your GitHub token stored in a password manager or locked notes app. Paste it at Step 5 each day. You only need to regenerate it every 90 days.

📍 The "Where Are We" Command

At any point in any Claude session — including a brand new conversation — you can type where are we and Claude will give you a full status update of everything built so far in the Markets with Rajan project.

The command will tell you:

  • What has been completed — reports generated, GitHub files pushed, skills built
  • What is currently in progress — any partial task or open decision
  • What is pending — any task Claude suggested that you have not yet decided on or started
  • Where you can pick up from — so you can continue from exactly where the last session ended

Example: if Claude suggested "We can also add an email subscription widget to Blogger" in a previous session and you haven't acted on it yet, where are we will remind you of that open item so it doesn't get lost across sessions.
